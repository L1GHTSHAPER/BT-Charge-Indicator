# BT Charge Indicator

在 Windows 系统托盘中显示蓝牙设备的电量，支持耳机、键盘、鼠标、手柄等设备，并提供低电量提醒。

## 下载与运行

1. 打开 [GitHub Releases](https://github.com/L1GHTSHAPER/BT-Charge-Indicator/releases/latest)。
2. 在发布附件中下载 `BTChargeIndicator.exe`。
3. 将文件放到固定文件夹，双击运行；无需安装或单独安装 .NET 运行时。
4. 在系统托盘中找到电量图标，右键打开设备列表和设置。

中文支持需包含本次改动的构建；旧版发布文件只有英语和俄语。

## 语言

右键托盘图标 →“语言 / Language”→“简体中文”。选择后立即生效，并保存供下次启动使用。

“自动（跟随 Windows）”模式下，中文 Windows 使用简体中文，俄语 Windows 使用俄语，其他语言使用英语。英语和俄语仍可手动选择。设备名称保持原样；Windows 自带消息框的通用按钮由系统语言决定。

## 常用设置

- **托盘图标样式**：选择大号数字、电池、圆环、条形等显示方式。
- **刷新间隔**：选择 30 秒、1 分钟或 5 分钟，也可以点击“立即刷新”。
- **低电量提醒**：开启提醒并设置低电量阈值。
- **设备连接通知**：开启或预览连接、断开时的动画。
- **登录 Windows 时自动启动**：设置登录后自动运行。
- **自动检查更新**：检查并提醒有新版本，不会自动覆盖当前程序。

托盘图标默认显示计入统计的已连接设备中最低的电量。设备子菜单中的“计入托盘图标电量”可以控制该设备是否参与统计；“在列表中显示”和“此设备低电量提醒”可单独设置。

双击托盘图标可打开 Windows 蓝牙设置。

## 设备兼容性

程序读取 Windows 提供的设备电量属性、HFP/PnP 电量信息和标准 BLE GATT 电池服务，并支持部分耳机与手柄的专用协议。

能否获得电量、刷新频率及电量精度取决于设备固件和 Windows 驱动。没有可用数据时显示未知状态，不会推测百分比。可以在设备子菜单中打开“设备诊断”查看数据源。

## 从源码构建

需要 Windows 10/11 和 .NET 9 SDK。在项目目录运行：

```powershell
.\build.ps1
```

生成的独立单文件程序位于 `dist\BTChargeIndicator.exe`。

运行项目现有测试：

```powershell
dotnet run --project Tests/BTChargeIndicator.ProtocolTests.csproj
```
